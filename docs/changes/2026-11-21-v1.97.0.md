# Tlamatini v1.97.0 — Released

**v1.97.0 is the latest released version** of Tlamatini and Tlamatini-Spanish.
Both editions use this one release number and retain their respective language,
accounts and installation paths.

## A Canvas for several documents

Keep up to **32 text, source, Markdown and PDF documents** open in independent
tabs. Switching preserves each buffer, undo history, selection, reading position,
encoding and save target. Markdown retains Preview/Source and its resources;
PDFs retain their viewer and page, zoom, rotation and scroll position.

The active tab determines Copy, Save, Refresh and document-toolbar actions.
An asterisk marks unsaved changes, including those in inactive tabs. Closing a
dirty tab asks before discarding its edits. Page-departure protection checks
every dirty tab and pending save; the browser controls its final warning.
Save before leaving: open editors are not recovered after reload or a crash.

With Canvas focus, **Alt+PageUp / Alt+PageDown** switches documents. Ctrl+Tab
and Ctrl+Shift+Tab work only when the browser delivers them to the page;
Chrome normally reserves them for browser tabs.

## Choose exactly what becomes chat context

Open tabs are **not automatically context**. Use **Use as context** on one or
several documents to select explicit snapshots, leaving other documents open
only for reference. Accepted snapshots appear on their tabs and in the
**Chat context** strip. Editing, refreshing or saving does not silently replace
the accepted snapshot: **Context · older / Update context** asks for an explicit
update. Closing a tab retains its selected context until its chip is removed.

The selected set accepts up to **32 documents and 32 MiB of prepared UTF-8
text**, including separators; model context capacity remains a separate limit.
An oversized or invalid replacement is refused without silently truncating it
or replacing the previous accepted set. PDF context uses normal preparation
and an account-bound prepared token; viewing the PDF alone never selects it.

Acknowledgements identify the accepted documents and revisions. A lost
connection keeps the open editors but clears confirmed context badges and asks
the user to reconnect and verify the selection. A lost acknowledgement is not
reported as success. Account-owned mutations are serialized across browser
connections, including legacy context and reconnect operations.

## Interactor follows the document, not just the editor surface

Interactor can list document metadata, read the active document and activate
another exact document during a lesson. Document IDs and revisions bind each
operation; a stale edit is refused instead of reaching a different tab.
Switching documents stops typing aimed at the former document. Live editor
consent, cancellation and user keyboard control remain in effect. PDF documents
can be activated and read in their viewer, but are not editable text buffers.

## Carried improvements

The [1.96.1 release](2026-11-21-v1.96.1.md) removed the obsolete Voice Commands
catalog section in favor of the microphone beside Send. Its two cards remain
hidden without renumbering the catalog. Tlamatini-RC integration, approval sync,
continuous voice, account-owned Torrenter downloads, readable Markdown and
matching Private/Public builds remain part of the release. See the
[remote-control guide](../remote-controller.md) and earlier dated release records
for their implementation and verification boundaries.

## Documentation and verification

The English and Spanish user guides, self-knowledge, maintainer references,
Canvas/Markdown/PDF/Refresh/Interactor guides, quick reference and PDF/PPTX
documentation describe the same multi-document behavior and version 1.97.0.
Historical records, dependency pins and dated test results retain their identities.

The [Canvas verification record](2026-11-21-canvas-document-tabs.md) separates
visible browser scenarios from backend ownership/persistence tests, native file
saves, prepared PDF tokens and actual PDF rendering. Its recorded source tests
do not claim a new executable build or installed-release acceptance run.

Read the [Canvas guide](../canvas-editing.md), [PDF guide](../pdf-canvas.md),
[Refresh guide](../canvas-refresh.md) and [Interactor guide](../interactor.md)
for actions, limits and recovery behavior.
