## What is new

* **Terminater** (workflow agent #86, `chat_agent_terminater`): real `cmd.exe` and PowerShell
  terminals in a **Terminals** area (**Views ▸ Terminals**, or Ctrl+`) on the chat, the
  Agentic Control Panel and the Prompt Flow Panel. Tlamatini types every key like a person
  (about 50 words per minute, never pasted), waits for the command, reads the whole output
  back and reports the exit code. Esc takes the keyboard; `<<USER:hint>>` hands it over on
  purpose; a command silent for 45 seconds is flagged `hung` and can be aborted. One hub in
  the Django process owns the shells, so closing a page never closes one. It is the 67th
  wrapped chat agent, sits on the Ask Execs allowlist, is the eighth Prompt Flow Panel
  operation and has three safe cards in the Catalog of Prompts (127-129, *Run & Execute*).
  The full contract is [docs/terminater.md](../terminater.md); the record with its evidence
  and the defects found on the way is [2026-10-19-terminater.md](2026-10-19-terminater.md).
* **The build proves it.** `check_terminater` drives a real PowerShell, a real `cmd.exe`, the
  shipped pool agent under the carried Python and a WebSocket round trip inside the freshly
  frozen app, and packaging stops if it fails.
* **The private release carries the builder's data.** `build_complete_private_release.py`
  merges every External MCP server of the installed copy, and its active selection (at most
  five), into the gitignored `external_mcps.private.json`, and ships the whole `data.keys`
  vault as `<install>/data.keys`. The public builder refuses both, `build.py` aborts if the
  vault is requested with the public catalog, and the new file is excluded from the
  self-modify snapshot. Record:
  [2026-10-19-private-release-data.md](2026-10-19-private-release-data.md).
* **Documentation, skills, PDFs and deck brought to the same state.** The assistant guides,
  `docs/claude/*`, the Book, the README, the self-knowledge file, FlowCreator's skill, the
  skill mirrors, the architecture atlas (`Tlamatini-Architecture.pdf`) and the project
  dossier (`tlamatini_app_summary.pdf` and the PowerPoint deck) describe the same release.
