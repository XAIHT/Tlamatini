# v1.87.0 — Release record

**Tlamatini v1.87.0 was tagged on 2026-10-18.** This dated record describes that release;
[current guidance is v1.91.1](2026-10-27-v1.91.1.md). It
brings a leaner agent catalog (**85 workflow agents**), a removal that moves the
installation aside instead of copying it, a smaller frozen release payload, a
Usage menu that waits for real data, and a Python quality gate. It also carries
**v1.86.0** (tagged 2026-10-17): Mover creates a new folder name as a folder, and
the Architecture atlas can be rebuilt from the repository. This record reconciles
the repository through commit `826c7c1a` and this consistency sweep.

## Using the changes

- **85 agents.** Gatewayer, Gateway-Relayer, Node-Manager and Zavuerer are gone
  from the canvas, the sidebar, the chat tools and the Catalog of Prompts. A flow
  saved with one of them needs that node replaced. Messaging stays on Telegrammer,
  Whatsapper, Emailer and Instant Messaging Doctor.
- **Uninstalling is fast and recoverable.** The Uninstaller moves the
  application entries into a recovery folder on the same drive instead of copying
  and hashing the whole installation. If a reversible step fails, the entries and
  the Windows state are put back. If the application is removed but a locked file
  stays behind, the window says **Application removed; cleanup incomplete**, lists
  what remains and offers **Retry cleanup**; reopening the Uninstaller can finish
  it later. `agents/` and the six content folders that hold files are kept, as
  before. See [the setup windows](../setup-wizards.md).
- **About ▸ Usage** shows **Checking usage…** until real report data arrives,
  explains connection problems under **Connection details**, keeps valid credits
  visible when only the account name is missing, and retries by itself. See
  [Usage](../usage-dashboard.md).
- **Mover** (v1.86.0): a destination such as `scripts/architecture_atlas` that
  does not exist yet is created as a **folder**, and the file keeps its own name.
  A rename still happens when the destination names a file (it exists as a file,
  has an extension, or the source has none either); a trailing slash always means
  a folder.
- **Architecture atlas** (v1.86.0): `python scripts/architecture_atlas/build_architecture_pdf.py`
  regenerates `Tlamatini-Architecture.pdf` with Tlamatini's own LaTeXer and
  verifies that every tracked file appears in it. See
  [its README](../../scripts/architecture_atlas/README.md).

## Maintainer rules

Never renumber a prompt or re-edit an old migration to remove an agent: add a
forward migration like 0214. A removed agent must disappear from the template
folder, the display-name map, contracts, wrappers, capability hints, canvas
handlers, CSS, FlowCreator's skill file, the FlowHypervisor prompt, catalog
prompts, `regen_secrets.py` and every document in the same pass. Removal must
never recursively erase the installation root, never copy the payload to make
it reversible, and never report a timed-out cleanup as success.

At the time of this record, the current release number was **v1.87.0** on every active documentation and
generated-artifact surface. Historical feature introductions and dated evidence
retain their original versions. Run all development commands and verification
in a confirmed visible foreground console or headed browser, as required by the
[execution policy](../../TestsVisiblesAndVisibleExecutionFromClaude2Codex.md).
