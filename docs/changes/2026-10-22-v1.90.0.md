## Workflow and safety boundaries

Enable Multi-Turn, the Interactor tool in Config → Configure MCPs/Tools, and
Live editor above the canvas. “Using your editor” or “using your text editor”
selects this module. A new document without a user-supplied path is created
exclusively under `Temp/interactor/<account>/<random>/`, using the requested
filename. No existing file is overwritten by `new`.

`read` returns the live buffer, selection and revision. `type` uses a checked
document/revision and one undoable teaching segment. `guide` hands a bounded
field to the user and ends the mutation portion of that chat turn. Continue
starts an ordinary new chat turn and a fresh read; it does not silently submit
the learner's answer. Typing is neither saving nor executing code.

The user can interrupt through input, selection, Escape, Stop or chat
cancellation. A document replacement invalidates pending work. A hidden tab can
pause for up to two additional minutes; a timeout does not replay partially
typed text. Explicitly hiding the canvas or switching Markdown to Preview
hands control back to the user.

Native save access belongs to both account and login session, is loopback-only
and CSRF-protected, expires after 12 idle hours and disappears on server
restart. A browser cannot supply an arbitrary host destination path. Writes
compare revisions, stage beside the destination and preserve recoverability.
Ask Execs gates Interactor `new` and `save`; stale edits and unavailable access
are refused independently of that switch. The database backup/restore
mechanics are unchanged.
