## Changes after the tag

At `74e06a6c`, the workspace handles a queued magnet when all four metadata slots are busy. It keeps the inspection ID while waiting. Jobs owns the transfer and publishes a hash-verified copy to Windows Downloads under `Torrenter/<account UUID>/<job ID>/`. If Downloads is unavailable, it tries the edition’s `content_generated/Torrenter/` tree. The manifest shows the actual destination. A private service copy alone does not establish delivery. Private source references and activity logs belong under the edition’s `TorrenterData` directory.

Executer preserves shell assignments such as `set PLAYWRIGHT_BROWSERS_PATH=…` when parsing a command with wrapper options. It resolves the configured timeout after loading the agent configuration. The Windows packaging checks require the pywin32 extension modules used by the frozen controller. The update compares the inner and outer uninstaller against the runtime receipt. During uninstall, literal cache directories whose names end in a space or period remain distinct from the normal `ms-playwright` directory, including during rollback. The update cleanup helper refuses to operate outside the intended installation.
