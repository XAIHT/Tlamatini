# v1.91.1 — Prompt Flow fixes and short tool names

## Version and delivery

**Current version: v1.91.1, dated 2026-10-27.** The annotated tag resolves to
`9915938aca55060980f1b0245f02cae67fbffdd0` (`9915938a`) and is present on origin. It is
published on GitHub as the Latest release ("Tlamatini v1.91.1 Win11x64"), replacing
v1.91.0, which was published on 2026-10-23 from tag `a771d27c`. `package.json`
mirrors `1.91.1`; runtime/build versioning continues to use the existing resolver.

v1.91.1 is a patch release on top of [v1.91.0](2026-10-23-v1.91.0.md). It adds no
workflow agent, tool, skill or migration: the catalog stays **86 workflow agents,
67 wrapped chat agents, 110 built-in tools (21 + 67 + 12 + 10), 29 skills and 220
migrations**. Everything in v1.91.0, including Config → Live Editor & Terminater,
is carried unchanged.

## What changes for the user

| Area | Before | Now |
|---|---|---|
| Prompt Flow history | A Prompt step could be answered with the history of another conversation, because the chains loaded the newest saved messages without saying whose. | Every chain loads the history of the request's own `conversation_user_id`. A Prompt Flow run key is not an account, so the run uses only its own in-memory history. |
| YES/NO Decisions | An `equals` Decision compared the whole answer, so `## YES - the toolkit is current ...` was "not YES" and the flow took the wrong branch. | `equals` also accepts an answer that opens with the value as its verdict (`Yesterday` still does not equal `yes`). The Prompt right before such a Decision asks the model to put the short answer alone on the first line. |
| Usage | A Prompt Flow run was recorded under its run key, not an account. | A run is recorded for the account that owns it (`prompt_flow_panel_<account>_<run>`); an id that is not an account is not recorded, and the log says so. |
| Telegrammer | "Using the bot X" written as words after the assignments was ignored, so the auto route sent from the user's own account. | Those words anywhere in the request (never inside a quoted value) select `provider=bot`. An explicit `provider`, including `telegram.provider`, still wins. |
| Short tool names | A model that called a wrapped agent by its short name (`terminater`) was told the agent was unavailable. | The name is resolved to the bound tool (`chat_agent_terminater`) and the correction is logged as `--- [TOOL-ALIAS]`. |
| Prompt Flow tab title | An Untitled flow showed "Untitled" in the browser tab. | The tab shows the file the flow was opened from or saved as. |

## Implementation

| File | Change |
|---|---|
| `agent/chat_history_loader.py` | A non-numeric conversation id returns no database history instead of falling back to an unfiltered query. |
| `agent/rag/chains/basic.py`, `history_aware.py`, `unified.py`, `agent/rag/factory.py` | `DBChatHistoryLoader.load(limit=8, conversation_user_id=...)` on every load. |
| `agent/services/prompt_flow_panel.py` | `_equals()` with a verdict-first rule and `VERDICT_FIRST_HINT` before an `equals` Decision. |
| `agent/usage_tracking.py` | `_account_id()` maps a run key to its owning account. |
| `agent/chat_agent_registry.py`, `agent/tools.py` | `prose_mode_anywhere` for Telegrammer's `provider`; quoted values are removed before the words are read. |
| `agent/mcp_agent.py` | Short wrapped-agent names resolved in `MultiTurnToolAgentExecutor._invoke_tool`. |
| `agent/static/agent/js/prompt-flow-panel.js` | Tab title falls back to the file name. |
| `tlamatini/settings.py` | `STATIC_VERSION` suffix `-flow-title-1`, so browsers load the new script. |

No database mechanism, migration or dependency changed. The commits are `31df8a8c`
(short tool names, 2026-10-24) and `9915938a` (the rest, 2026-10-27).
