# v1.85.0 — Current release

**Tlamatini v1.85.0 is the latest released version.** The release brings canvas
Refresh, the Views menu, layout reset and a docked avatar centered over the full
Mic-to-Send button row. This record reconciles the repository through commit
`32a4a6d3` on 2026-10-16. The existing annotated `v1.85.0` tag is retained.

## Using the changes

- **Open** selects a document. **Refresh** rereads the original document without
  opening a chooser or writing to it. Unchanged text stays in place; a changed
  file replaces the complete displayed content. A failed read keeps the previous
  document and explains how to retry. See [Canvas Refresh](../canvas-refresh.md).
- **Views → Canvas** hides or shows the canvas. Hiding gives the chat the full
  width and keeps the open document, Markdown mode, PDF viewer, refresh source,
  draft, history and loaded context. Opening a document or a generated-file link
  shows the canvas automatically.
- The visibility preference is separate for each account in that browser. It
  survives reload and browser restart; another profile or origin has its own
  preference. Hiding the canvas docks the avatar and disables floating resize.
  Showing the canvas enables resizing again and leaves the avatar docked.
- **Views → Reset layout** shows both panes, restores the initial horizontal and
  vertical layout, and docks the avatar. It keeps documents, drafts and history.
- Shrinking the composer keeps the portrait and its frame centered between the
  Mic button's left edge and the Send button's right edge. Both pane dividers,
  narrow layouts and zoom preserve that alignment, with a 120 px minimum square.

## Maintainer rules

Preserve the original canvas DOM when hiding it. Never clear context to change a
view. Cancel active divider drags before changing layout. Move keyboard focus out
of a region before hiding it, and keep `aria-checked` in sync. Reset must not
erase content. Keep a staged PDF iframe attached while committing its new viewer.
Refresh must not infer content equality from file size or timestamp.

The current release number is **v1.85.0** on every active documentation and
generated-artifact surface. Historical feature introductions and dated evidence
retain their original versions. Run all development commands and verification
in a confirmed visible foreground console or headed browser, as required by the
[execution policy](../../TestsVisiblesAndVisibleExecutionFromClaude2Codex.md).
