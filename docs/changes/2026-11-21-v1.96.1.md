# Tlamatini v1.96.1 — Released

**v1.96.1 is a historical release** of Tlamatini and Tlamatini-Spanish. The latest released version is [v1.97.0](2026-11-21-v1.97.0.md).
This record brings together the changes since the 1.93.5 release record.
The editions retain their own language, accounts and installation paths.

## Voice Commands leaves the Catalog of Prompts

The microphone button beside Send records, transcribes and sends a prompt
directly, so the catalog no longer needs a Voice Commands section. Its two
cards, prompts 121 and 122, are hidden by a migration (0226 in Tlamatini, 0228
in Tlamatini-Spanish). No prompt is renumbered or deleted, and the catalog now
opens with Getting Started. `PROMPT_CATEGORY_ORDER` no longer lists the section,
and `agent/test_voice_commands_catalog.py` guards that it stays removed.

Existing installations receive the migration through the normal post-update
`migrate`.

## Carried Tlamatini-RC releases

This release carries the work released as v1.94.0, v1.95.0 and v1.96.0:

- **v1.94.0** — Tlamatini-RC kicked off.
- **v1.95.0** — continuous Tlamatini-RC improvement and control-plane improvements.
- **v1.96.0** — Tlamatini-RC stage 2: hosted remote control, approval sync and
  hardening; Talker's default model is `legraphista/Orpheus:latest`.

See [Remote-Controller](../remote-controller.md) for the integration contract.
