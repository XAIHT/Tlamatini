## What changes for the user

**Config → Live Editor & Terminater** opens a shared dialog with three tabs.
The canvas and terminal Settings buttons also open it. The same account preferences
are available in chat, the Agentic Control Panel and the Prompt Flow Panel.

| Tab | Controls that affect real behavior |
|---|---|
| Live Editor | 40–160 WPM, linked terminal speed, segment pauses, teaching detail, field suggestions, ghost text/choices, cursor following, font size, line numbers and wrapping |
| Terminater | 20–160 WPM, available default shell, task-controlled or user-only Enter, advisor, command wait, no-output threshold, handoff wait, font, cursor and preferred layout |
| Voice | Narration for commands and teaching segments, explanation/literal/both, before/during/after, completion before typing, result announcements, shared voice controls and immediate mute |

Standard and Guided learning presets populate a draft. Preview demonstrates typing
and voice without editing a file or executing a command. Save applies behavior to
the next action; Cancel, Escape and Close discard unsaved settings. Stop, mute and
the current tab's Live editor permission are explicitly immediate. Appearance is
stored per account in that browser; behavior is stored for the account on the server.
The existing Voice settings select the browser voice, rate, volume and pitch.

Teaching detail is an instruction supplied to the language model, so its exact
wording remains model-dependent. Shell/advisor defaults affect newly opened terminals.
A command wait timeout returns control without killing the shell process.

## Implementation and compatibility

| Responsibility | Source and contract |
|---|---|
| Schema, validation and persistence | `agent/interaction_settings.py`, `InteractionSettings`, migration `0220_interaction_settings`; authenticated CSRF-protected `/agent/interaction-settings/`, strict ranges and optimistic revision conflicts |
| One terminal policy path | `terminal_hub.py` and the stdlib engine apply preferences to chat, ACP, Prompt Flow and browser dispatch; private action snapshots are overwritten server-side |
| Flow inheritance | New configurations use `use_my_defaults`; older files retain explicit values. Manual Enter and narration remain account choices. Typed chat preserves an explicitly requested shell |
| Manual Enter | Rejects automatic Enter and embedded control characters, including aliases and base64 text; the user's own keyboard remains in control |
| Editor | Settings snapshots travel with existing authenticated actions and revision receipts; saved speed, pause, suggestions, following and appearance reach the real CodeMirror buffer |
| Narration | `interaction_narration.py`, `voice_runtime.js` and `interaction_speech.js` share one cancellable speech queue and select one focused account tab |
| Before-typing receipt | A real completion/explicit skip is required when waiting is enabled; missing listeners, Stop or disconnect cancel instead of silently typing; no reconnect replay |
| Private input | Secret-marked text and user handoff values are excluded from speech; outcome announcements describe status without reading output aloud |
| Terminal redraw | Prompt anchoring survives font/layout resize using the actual screen, preserving honest command read-back |
| Carriage | Offline editor bundle, templates, CSS/JS, frozen imports and source/runtime inventories carry the complete implementation |

No new workflow agent or tool registration is added. Database backup/restore and
installation mechanics are unchanged. Existing keyboard takeover, Ask Execs,
account/session isolation, bounded visibility recovery and no-paste typing remain.
