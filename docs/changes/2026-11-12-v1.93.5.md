# Tlamatini v1.93.5 — Released

**v1.93.5 is the latest released version** of Tlamatini and Tlamatini-Spanish.
This record brings together the changes since the 1.92.4 documentation update.
The editions retain their own language, accounts and installation paths.

## Explain the exact canvas selection

**Explain selection** captures all selected ranges, including unsaved edits, at
click time. With no selection it captures the current file. Its dedicated
read-only request works independently of all eight chat checkboxes, Live editor
permission and the Interactor tool. It preserves the composer draft and editor
selection, and uses no tools, prior conversation or loaded document context.

A small selection from a large file no longer fails because a full-buffer
Interactor receipt exceeds the tool-result budget. Up to 64 ranges and 262,144
UTF-16 units are accepted, subject to the model's real context capacity; excerpts
are not silently truncated. Normal Interactor tutoring keeps its separate
complete-document read contract.

See [canvas editing](../canvas-editing.md),
[Interactor](../interactor.md) and the
[12 November evidence](2026-11-12-canvas-selection-explanation.md).

## Executer returns when its script finishes

The blocking script path now captures stdout/stderr in unique regular files
inside its run directory. It waits for the direct script process and reads a
bounded snapshot through separate handles. A detached child retaining inherited
output handles no longer delays the launch receipt until that child exits.
Direct commands still wait normally; explicit detached children can keep running.

The exact Rust cube executable and launch structure reproduced the defect.
The original implementation delivered its result after the cube closed; both
corrected editions delivered it in about five seconds while the cube was alive.
No generic loop guard or new model prompt was added.

The separate final-chat-response delivery gap in the original trace remains
unresolved. This capture fix does not establish its cause. See
[the reproduction and limits](2026-11-12-executer-output-capture.md).

## Speech continues when the browser loses focus

Shared speech no longer deliberately pauses when the browser is covered,
minimized or unfocused. Failed chunks are retried, with a Windows host-voice
fallback. Closing or reloading a page during ordinary chat speech attempts to
hand over the remaining text; a completed answer can be announced when no chat
page is open for the account.

Mute, listening, Escape and explicit stop controls remain effective. Host
playback requires the running application, Windows audio and an available female
voice; the Spanish edition preserves its language requirement. Interaction
narration retains its own cancellation and ownership rules. See
[voice playback](../voice-playback.md) for practical limits.

## A direct account wizard and directory inventory

The shipped account-creation card opens this instance's real Django
`createuserconsole` using the current runtime and database. It yields chat while
the user enters private account details in the console. Ask Execs and cancellation
remain enforced; DONE/HECHO verifies the newly persisted administrative account.
Known default cards are updated by migration 0223 while customized cards remain
intact. See [the wizard guide](../user-creation-wizard.md).

A standalone question asking for available directories returns the active
path-guard roots directly, without a model intent decision or disk scan.
It grants no extra access; mixed requests keep normal checks. See
[available directories](../available-directories.md).

## Torrenter reporting and completion waits

The workspace supports sortable data columns, multiple sort priorities, filters,
paging and saved account/browser display preferences. Completed downloads remain
completed when their peer session is stopped. Recovery choices distinguish Start,
Resume and Recheck; old errors and current delivery failures remain separate.

Completion waits renew expired credentials and tolerate brief Jobs outages.
A paused unfinished download ends the wait. A persistent outage ends it after
10 minutes, a failed delivery gets up to 3 minutes to recover, and two hours
without observed progress or traffic ends the wait with recovery guidance.
Ending the wait does not cancel the service transfer. Verified publication is
still required before claiming that files were delivered.

Jobs scheduling and disk-publication changes require the separately installed
Jobs service. Updating Tlamatini does not replace that service. See
[Torrenter](../torrenter.md) and the
[10 November verification](2026-11-10-torrenter-recovery.md).

## Model defaults and carried improvements

Initial text and reasoning defaults use `deepseek-v4.1-flash:cloud`; vision keeps
`mistral-large-4:cloud` and `gemma4:cloud`. Existing custom model choices remain
selectable. Talker retains `legraphista/Orpheus:3b-ft-q8`.
See [model configuration](../model_configuration.md).

The release also carries the matching-version combined builder, explicit
embedded release identity, isolated build environments, updater/uninstaller
carriage and byte-preserving readable Markdown handling documented in
[1.92.4](2026-11-08-v1.92.4.md).
