\section{The Translation Boundary}
\label{sec:translation-boundary}

Before any algorithm, the scope must be exact. This section is the contract.

\subsection{Two channels, one rule}
\label{sec:two-channels-one-rule}

Every string in the system belongs to exactly one of two channels.

\begin{table}[htbp]
\centering
\footnotesize
\caption{The two channels. Every string in the system belongs to exactly one of them.}
\label{tab:two-channels}
\begin{tabular}{@{}p{0.13\linewidth}p{0.38\linewidth}p{0.41\linewidth}@{}}
\toprule
 & \textbf{Presentation channel} & \textbf{Machine channel} \\
\midrule
\textbf{Definition} & Read by a human, never read back by a program & Consumed, compared, routed on, persisted, or parsed by a program \\
\addlinespace
\textbf{Audience} & The Spanish-speaking operator & The interpreter, the filesystem, the parser, the model's tool interface \\
\addlinespace
\textbf{Language} & \textbf{Spanish} (fully) & \textbf{English, byte-identical, forever} \\
\addlinespace
\textbf{On error} & Cosmetic --- a clumsy sentence & Catastrophic --- wrong tool, wrong path, silent corruption \\
\bottomrule
\end{tabular}
\end{table}

The rule is one sentence:

\begin{keyinsight}
\textbf{Translate what the user reads. Never translate what the machine reads.}
\end{keyinsight}

\subsection{What becomes Spanish}
\label{sec:what-becomes-spanish}

The entire visible surface. This is not a subset; it is everything a human eye lands on.

\begin{itemize}
  \item \textbf{Navigation and chrome} --- the navbar menus and every dropdown item, dialog titles, section legends, tab labels, panel headings.
  \item \textbf{Controls} --- every button caption, checkbox and toggle label, radio label, the toolbar, the Send/Cancel affordance, context menus.
  \item \textbf{Input affordances} --- placeholders, tooltips, \code{aria-label} accessibility text, helper text, character counters.
  \item \textbf{Generic verbs and nouns of the interface} --- \foreignlanguage{spanish}{\emph{Guardar, Cancelar, Continuar, Cerrar, Eliminar, Ejecutar, Detener, Validar, Iniciar, Pausar, Reanudar, Buscar, Importar, Exportar, Actualizar, Reintentar}}.
  \item \textbf{Instructional prose} --- wizard steps, the setup guidance, the ``how to use this'' copy, empty-state explanations, confirmation questions.
  \item \textbf{Feedback} --- status lines, progress messages, success and failure notices, validation warnings, permission prompts, the interrupted-execution banner.
  \item \textbf{Report chrome} --- the Exec Report's title, its column headers (\foreignlanguage{spanish}{\emph{Comando}}, \foreignlanguage{spanish}{\emph{Estado}}), its verdict words (\foreignlanguage{spanish}{\emph{ÉXITO}}, \foreignlanguage{spanish}{\emph{FALLO}}), the denial banner's labels.
  \item \textbf{Catalog content} --- the prompt catalog's category names and card descriptions.
  \item \textbf{Agent descriptions} --- the tooltip and description text explaining what each agent \emph{does}.
  \item \textbf{The model's answer prose} --- the sentences Tlamatini writes back.
  \item \textbf{Documentation and onboarding} intended for the operator.
\end{itemize}

\subsection{The Naming Invariance Rule}
\label{sec:naming-invariance-rule}

Stated as an operational rule an engineer can apply without judgement:

\begin{principle}[RULE N]
An agent's display name is an \textbf{identifier}, not a label. It is byte-identical in every locale, in every surface, forever --- including its exact capitalization, its hyphens and its spaces. What is translated is the agent's \emph{description}, never its \emph{name}.
\end{principle}

\subsection{Why the boundary is a precondition, not a compromise}
\label{sec:boundary-precondition}

It would be easy to read \S2.3 as a limitation accepted for expediency. It is the opposite. The naming invariant is what \emph{creates} the guarantee.

The reason is developed formally in \S3.2 and \S6.9, but the intuition is short: the correctness guarantee works by proving that the \emph{execution channel} is unaffected by the user's language. That proof requires the execution vocabulary --- the set of tool names, agent identities, argument keys, enumerated values and sentinels --- to be \textbf{the same set of symbols regardless of locale}. If \code{Emailer} becomes \code{Correero} in Spanish, then the action space itself is locale-dependent, the English baseline and the Spanish pipeline are no longer comparable objects, and there is nothing left to prove non-inferiority \emph{against}.

Additionally, and independently of the proof, the codebase makes this rule load-bearing today: agent display names are simultaneously the sidebar label, the value of \code{data-content} attributes matched by \textbf{56 case-sensitive CSS attribute selectors}, the operand of roughly \textbf{512 lowercased string comparisons} in the canvas connection handlers, the key of the per-agent enable gate \code{agent\_\textless display\textgreater\_status}, and the discriminant in \textbf{138 \code{case} labels} in the flow loader. The project's own engineering notes already record that changing a single hyphen to a space in one of these names \emph{silently stops canvas connections from being persisted, with no error anywhere.} The naming convention is not decoration. It is an ABI.
