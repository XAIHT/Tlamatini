\section{The Model May Not Speak Spanish}
\label{sec:model-may-not-speak-spanish}

This section answers the question the whole design exists for: \textbf{the operator
can bind any model, including one with no useful Spanish at all. How is correctness
still guaranteed?}

\subsection{A taxonomy of model deficiency}
\label{sec:taxonomy-of-model-deficiency}

``Not Spanish-capable'' is not one condition. It is four, and they fail in different
places.

\begin{table}[htbp]
\centering
\small
\caption{Four classes of model deficiency and where each one surfaces.}
\label{tab:deficiency-taxonomy}
\begin{tabular}{@{}p{0.16\textwidth}p{0.45\textwidth}p{0.27\textwidth}@{}}
\toprule
\textbf{Class} & \textbf{Description} & \textbf{Where it shows up} \\
\midrule
\textbf{C1 --- Weak generation} &
Understands Spanish; writes it awkwardly or drifts into English mid-answer &
Presentation channel only \\
\addlinespace
\textbf{C2 --- Weak comprehension} &
Misreads the Spanish request; chooses a plausible-but-wrong tool &
Execution channel --- tool selection \\
\addlinespace
\textbf{C3 --- Literal infidelity} &
Understands the request but ``helpfully'' normalizes a path, strips an accent,
translates a flag, re-formats a number &
Execution channel --- arguments \\
\addlinespace
\textbf{C4 --- Protocol damage} &
Emits a malformed sentinel under a non-English instruction (\code{VEREDICTO:}
instead of \code{VERDICT:}) &
Downstream routing --- silently \\
\bottomrule
\end{tabular}
\end{table}

C3 and C4 are the dangerous ones precisely because they are \emph{silent}: the action
looks well-formed and executes successfully against the wrong target.

Note what is \emph{not} in the recovery column: nowhere does the system rely on the
model becoming better at Spanish. \textbf{Spanish competence is an accelerant, not a
dependency.} A model that has none simply spends more rungs, and the operator notices
only a slightly slower answer.

\subsection{The capability profile}
\label{sec:the-capability-profile}

Because Corollary 1 makes the profile safe, it can be cheap. It exists solely to
answer \emph{``which rung should we start at?''}, and a wrong answer costs one extra
model call.

\begin{itemize}
  \item \textbf{Out of band, always.} A single global worker, never on the request
        path, refusing to run while a generation is in flight, hard wall-clock
        capped, with a partial result treated as ``start conservatively'' rather than
        as a verdict.
  \item \textbf{Cheap and few.} A handful of items exercising the four deficiency
        classes under the \emph{production} condition (English spine, Spanish answer
        required) at \emph{production} generation parameters --- because probing at
        temperature 0 systematically measures the best case.
  \item \textbf{Per-path, not scalar.} A model may write excellent Spanish prose and
        still mangle a \code{chat\_agent\_stm32er} argument list, so the profile emits
        a starting rung for the conversational path and another for the operator path.
  \item \textbf{Short TTL on the permissive side.} A stale ``competent'' verdict costs
        escalations that were already going to be caught; a stale ``incompetent''
        verdict costs only unnecessary English glossing. For cloud aliases and
        providers that expose no content digest, a daily single-call canary whose
        response hash acts as a poor-man's fingerprint detects a silent model swap
        that a version string cannot.
  \item \textbf{Never a denial.} A missing, unreadable or expired profile means
        \emph{start at R1}, not \emph{refuse Spanish}. There is no path by which an
        infrastructure failure removes the user's language.
\end{itemize}

Trace~C (Table~\ref{tab:trace-c-destructive-no-path}) is the strongest argument for the
architecture. The alternative behaviours are all worse: today's system tells the user
no tool is needed; a naive Spanish port would let a model guess a directory and delete
it. NEPANTLA refuses, explains, and asks --- because a literal with no provenance is
treated as an emergency rather than as a detail.

Note also that if the folder \emph{had} been established in a prior turn, it would be
in $\mathcal{H}$, provenance would pass, and V5 would route the action through the
Ask-Execs permission prompt --- rendered in Spanish, naming \textbf{Deleter} in English.

\subsection{The guarantee, restated for a hostile model}
\label{sec:guarantee-restated-hostile-model}

Take the worst admissible case: a model with no Spanish comprehension, no Spanish
generation, and a tendency to normalize literals. NEPANTLA's behaviour is then:

\begin{itemize}
  \item Execution: escalates to R3, which \emph{is} the English pipeline, with
        byte-exact literals. \textbf{$\theta \approx \theta_{EN}$.}
  \item Arguments: protected absolutely by V3. \textbf{Zero corruption.}
  \item Protocol: protected by V6; operator route pinned English for that model.
        \textbf{Zero silent routing damage.}
  \item Presentation: Spanish via the renderer, or Spanish-by-template as a floor.
        \textbf{The user never sees English.}
  \item Cost: 2--4 model calls instead of 1.
\end{itemize}

The user pays latency. They do not pay correctness, and they do not pay language.
